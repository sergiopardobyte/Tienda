# Tienda

Proyecto educativo desarrollado con HTML, CSS y JavaScript.

## Funcionalidades

Implementado hasta el punto 3.5:

- Catálogo de seis productos.
- Diseño adaptable a pantallas pequeñas.
- Agregar productos al carrito.
- Control de existencias disponibles.
- Contador de unidades.
- Cálculo del subtotal.
- Quitar productos del carrito.

El buscador y la confirmación de compra se implementarán después.

## Cómo ejecutar

1. Abrir el proyecto en Visual Studio Code.
2. Instalar Live Preview de Microsoft.
3. Abrir frontend/index.html.
4. Iniciar la vista previa.

## Comprobación

3 camisetas y 2 pares de zapatos deben dar un subtotal de $127.50.

El carrito se vacía al recargar la página.
